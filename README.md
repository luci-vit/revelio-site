# revelio-site

Protótipo de alta fidelidade do site do **Revelio** (IHC 2026.2): plataforma para criar, divulgar e viver eventos científicos. Next.js 16 (App Router) + TypeScript, só dados fictícios e estado em memória.

```bash
npm install
npm run dev        # http://localhost:3000
npm run typecheck  # tipos
npm run lint
```

Use o botão **Demonstração** (canto inferior direito) para alternar entre visitante, participante, autor, revisor e organizador.

- Regras e cenário: `docs/contexto.md`
- Protótipo de baixa fidelidade: `docs/prototipo/`
- Identidade visual: `docs/identidade/`
- Arquitetura do código: `docs/arquitetura.md`
